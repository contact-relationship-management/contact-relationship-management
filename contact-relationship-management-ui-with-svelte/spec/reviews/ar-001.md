## What a review covers

1. Every interface string, read in context in the running tour, not only in the file, with the
   strings identical to English in [locale-review.md](../locale-review.md).
2. Each plural group's forms for this language (`tests/unit/plurals.test.ts` holds which forms exist).
3. The words a data subject reads: the confirmation, preference and unsubscribe pages and the
   template fallbacks, in the service.
4. The import header names a spreadsheet in this language would use.

## Known weak spots

- Six plural forms per counted string (zero, one, two, few, many, other); the zero and one forms keep the digit beside the word, which a reader may find stiff.
- Right-to-left layout was checked in Chromium only, in the light theme; a Latin name inside an Arabic sentence is left to the browser's bidirectional algorithm (no `<bdi>`).
- Numbers are shown in Latin digits because that is CLDR's default for `ar-001`; whether a deployment wants Arabic-Indic digits is a choice not yet offered.
