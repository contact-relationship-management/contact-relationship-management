# 聯絡人關係管理

面向銷售、行銷和客戶支援的開源 CRM 軟體。

聯絡人關係管理用於跟蹤銷售、行銷和支援環節中與客戶及潛在客戶的關係。系統為每位聯絡人保留一條記錄，並要求在傳送訊息前已記錄同意。本軟體尚未準備好用於生產環境，使用合成資料執行。

## 優勢

- **統一的聯絡人記錄。** 銷售、行銷、支援和分析使用同一條記錄。
- **已記錄的同意。** 未記錄同意的聯絡人不會收到任何內容。每封電子郵件都包含經過簽名的退訂連結。
- **減少個人資料。** CRM 儲存的是對身份服務中某個人的引用，而不是姓名或地址的副本。
- **結果可解釋。** 潛在客戶評分依據可讀的規則計算，預測依據加權的銷售管道階段計算。
- **國際化設計。** 姓名、地址、日曆和書寫方向不受單一國家格式的限制。介面提供八種語言。
- **公開的規範。** 規範、程式碼和測試均已公開。文件說明了哪些功能已實現、哪些尚未實現。

## 功能

- **銷售。** 基於規則的潛在客戶評分、看板式交易管道和按階段加權的預測。
- **行銷。** 細分行銷活動和培育序列。除非配置郵件模式，否則傳送為模擬操作。
- **支援。** 帶優先順序和服務級別截止時間的工單，以及知識庫文章。
- **分析。** 用於檢視贏單率、各階段管道、行銷活動回報、服務級別狀況和客戶終身價值的儀表板。
- **資料品質。** 按機率檢測重複記錄，支援合併和撤銷。
- **治理。** 稽核記錄、基於角色的存取控制，以及對資料主體存取和刪除請求的支援。

## 入門

1. **獲取程式碼。** 克隆儲存庫。需要 Node.js 和 pnpm。
2. **啟動應用。** 在 Svelte 目錄中執行 `pnpm install`，然後執行 `pnpm dev`。
3. **登入。** 使用 `example@example.com`。不需要其他服務。
4. **檢視導覽。** 導覽使用虛構資料，涵蓋聯絡人、潛在客戶、交易、行銷活動、工單和管理層檢視。

[教程](../../docs/tutorial-first-tour.md)（英文）說明了每個步驟。[安裝和使用](../../INSTALL.md)（英文）介紹完整服務。
