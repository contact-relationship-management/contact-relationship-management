# 通往生產環境之路

> 聯絡人關係管理尚未準備好用於生產環境。本頁說明這裡所說的生產環境是什麼意思，以及各部分進展到了什麼程度。

本軟體使用合成資料執行。除非配置了真實的郵件模式，否則郵件為模擬傳送。請勿在其中放入真實的個人資料。

## 生產環境的含義

生產部署儲存真實人員的資料，並向他們傳送真實訊息。對本專案而言，這需要具備以下全部條件：

- **真實登入。** 每個請求都經過認證，存取規則與部署組織的角色一致。
- **合法傳送。** 每條訊息都有已記錄的同意，並在其傳送目的地的每一處法律下具有合法依據，且經由能夠處理退信、投訴和退訂的真實郵件服務商傳送。
- **獨立保證。** 專案以外的人員已測試安全性和無障礙性，發現的問題已修復或已被接受。
- **維運。** 已實際恢復過的備份、監控、事件處理流程，以及值班人員。
- **穩定性證據。** 在與部署環境相似的硬體上、在真實負載下長時間執行，沒有錯誤或變慢。

生產就緒由每個部署分別判定。部署方只能為其自身組織和收件人關閉部分關卡。本頁所依據的工程評估是 [spec/plan.md](../../../spec/plan.md)。未關閉的關卡見 [spec/tasks.md](../../../spec/tasks.md)。

## 就緒度

每個百分比都是 2026-11-13 根據任務清單作出的估計，而非測量結果。

- **認證與存取控制** (70%): 已建置透過 PASETO 權杖或 Keycloak/OIDC 登入、帶記錄級檢查的基於屬性的存取規則，以及未啟用認證即拒絕啟動的生產模式。尚無真實部署以其自身屬性啟用它們，執行矩陣也尚未覆蓋所有處理活動（CRM-G1）。
- **郵件投遞** (40%): 預設使用模擬傳送器，另有一個 SMTP 傳送器。尚無帶退信和投訴 webhook 或抑制列表的郵件服務商介面卡（CRM-T39）。
- **資料保護與電子行銷法律** (15%): 已建置同意記錄、資料存取、刪除和保留。尚未為本專案研讀任何地區的法律，對真實發送路徑的審查仍未完成（CRM-G2，[regulatory](../../../spec/regulatory.md)）。
- **獨立安全保證** (10%): 已編寫滲透測試範圍。尚未進行滲透測試、正式風險分析或認證（CRM-T42）。AI 安全稽核不屬於獨立保證。
- **無障礙** (50%): 針對 WCAG 2.2 A 和 AA 的 axe-core 自動檢查在每個頁面路由上均通過。尚未進行僅用鍵盤、使用螢幕閱讀器或 400% 縮放的人工稽核（CRM-T48）。
- **翻譯** (30%): 介面提供八種語言。英語以外的文字由機器撰寫，尚無母語使用者審閱。
- **維運** (30%): 維運手冊涵蓋備份與恢復、金鑰管理、靜態加密、事件回應和記錄保留。尚未測試過任何恢復，手冊中的上線檢查清單仍未完成。
- **效能與穩定性** (20%): 已有負載測試和一項長時間穩定性測試。穩定性測試已在演示環境上執行兩分鐘；尚無長時間執行，也沒有在類生產硬體上的基線。
- **發布完整性** (85%): 發布映象為多架構，已簽名並附有證明，簽名可以驗證。Actions 和映象按摘要固定，歷史記錄會掃描金鑰。尚未檢查已拉取發布映象的 amd64 部分，也還沒有第二個程式碼託管平臺（CRM-T192）。
- **持續整合** (100%): 一個指令碼在 GitHub Actions 和 Woodpecker 上執行所有檢查。兩個 Rust 程式碼庫和 UI 均設有 95% 行覆蓋率下限；瀏覽器、程式碼檢查、供應鏈、變更行變異和每週完整變異關卡均已啟用（CRM-T94）。
- **演示保護措施** (100%): 每位導覽訪客都會獲得一份獨立的演示資料副本，最多 200 份。演示預設關閉；設定 `CONTACT_RELATIONSHIP_MANAGEMENT_DEMO_TOUR=on` 才會啟用（CRM-T92）。

## 本頁如何維護

當某個關卡關閉時，請在包含該工作的同一提交中更改估計值及其依據，並連結相應任務。
