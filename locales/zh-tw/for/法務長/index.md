## 法律立場簡述

該儲存庫**尚未準備好用於生產環境**，使用合成資料。它不聲稱符合任何制度。它實現了支援若干制度的技術功能，並列出了部署方必須補充的內容（[regulatory](../../../../spec/regulatory.md)）。

## 涉及的制度

| 制度 | 軟體提供的支援 | 您必須提供的內容 |
|---|---|---|
| 英國/歐盟 GDPR | 同意歷史、主體存取匯出、刪除（存在未了結義務時被拒絕）、保留清理、資料最小化、讀取稽核 | 每項處理目的的合法依據、DPIA（[模板](../../../../spec/compliance/dpia-template.md)）、處理活動記錄、保留計劃、控制者/處理者角色 |
| PECR / 電子隱私 | 以同意為條件的傳送、即時退訂 | 真實發送方的發件人身份標識和軟性選擇加入（soft opt-in）的決定 |
| HIPAA（如涉及美國健康資料） | 稽核控制、存取控制、完整性、傳輸安全功能 | 商業夥伴協議（BAA）、風險分析、政策、員工培訓。該軟體不會讓您自動合規 |
| NHS DTAC / DCB0129/0160 | 證據草稿（[dtac-supporting](../../../../spec/compliance/dtac-supporting.md)） | 指定的臨床安全官、危害記錄、認證。評估認為 DTAC 很可能不適用 |
| 無障礙（WCAG 2.2 AA，公共部門） | 自動化檢查和如實的聲明 | 在作出任何合規聲明之前進行人工稽核（T48） |
| 政府安全（NIST 800-53、ISO 27001、Cyber Essentials） | 控制對映（[control-mapping](../../../../spec/compliance/control-mapping.md)） | 認證和獨立保證 |

## 您需要但尚不存在的合約

1. 與電子郵件服務商的資料處理協議和跨境傳輸條款（T39）。
2. 與滲透測試機構的工作說明書和保密條款（T42）。
3. PostgreSQL、Redis 和記錄的託管及子處理者條款。
4. 許可證：見 [LICENSE.md](../../../../LICENSE.md)；儲存庫還附有安全、治理和 AI 使用聲明。

## 具體的法律注意事項

- **刪除**會將聯絡人匿名化，並在存在未結交易、工單或有效的培育登記（nurture enrolment）時被拒絕；稽核鏈會保留操作記錄，因此請在您的 DPIA 中說明這與刪除請求之間的關係。
- 對已遮罩資料的**破玻璃**讀取，只有在您記錄在案的依據之上才合法；理由欄位是證據，而不是授權。
- 線索**評分**：如果它將來影響對個人的重大決定，則適用自動化決策規則（[regulatory](../../../../spec/regulatory.md)）。
- **API 承諾：** [api-lifecycle](../../../../spec/compliance/api-lifecycle.md) 規定在移除 API 變更之前有 180 天的通知期。這是維護者的選擇；如果客戶將依賴它，請決定是否應寫入合約。
- **公開聲明：** 不要聲稱合規、認證或獲得批准。
