# 致人資長

> 工程簡報，不是法律意見、認證或稽核。內容反映截至 2026-10-11 程式碼儲存庫所顯示的情況。本文不聲稱已獲得任何認可。

## 為什麼人對這個產品很重要

對個人資料的存取由角色決定。軟體會執行一個人的權杖所聲明的內容；**誰獲得哪個角色、何時被收回，是一項人員流程**，這是儲存庫無法替您完成的。

## 軟體為您的流程提供了什麼

- **基於角色的可見性：** 部分角色看到的聯絡管道、交易金額和資金檢視是遮罩的；經理、管理員和服務層級可以看到更多（[auth](../../../../spec/auth.md)）。
- **被稽核的讀取：** 讀取個人資料會留下點名到具體人員的軌跡。應在上線前告知員工。
- **緊急存取：** 一個人可以獲得最長 60 分鐘、需說明理由的讀取提權；事後必須由另一個人審查。兩方都需要培訓。
- **空閒登出：** 瀏覽器中空閒 15 分鐘後登出。
- **無障礙：** 有公開聲明和自動化檢查；人工稽核（T48）仍然需要殘障使用者和輔助技術測試人員。
- **語言：** 介面已翻譯為 8 種語言區域；這些譯文**尚未**經過母語者審閱。

## 您的職責

| 領域 | 行動 |
|---|---|
| 入職、調動、離職 | 透過您的身份提供方授予和收回角色；CRM 會拒絕過期權杖，但不管理帳戶 |
| 培訓 | 資料保護、同意規則、破玻璃的使用與審查、無障礙實踐 |
| 政策 | 可接受使用、監控告知（讀取會被稽核）、對濫用緊急存取的紀律處理途徑 |
| 審查人員的能力 | 指定誰來審查破玻璃授權，以及其不在時的代理人 |
| 招聘 | 專案所需的角色：獨立測試聯絡人、屬於 NHS 範圍時的臨床安全官、資料保護負責人、無障礙負責人 |
| 員工關懷 | 為處理敏感個案的員工提供支援；CRM 不是個案管理系統，但可能儲存敏感的關係資料 |
