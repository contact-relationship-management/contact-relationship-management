# 致資訊長

> 工程簡報，不是法律意見、認證或稽核。內容反映截至 2026-10-11 程式碼儲存庫所顯示的情況。本文不聲稱已獲得任何認可。

## 資訊與資料視角

這個 CRM 儲存的是**關係資料**：聯絡人和帳戶（對其他系統中所持識別符號的封裝）、活動、交易、工單、同意歷史和稽核記錄。人口統計資訊被有意保留在身份註冊系統中（[domain-model](../../../../spec/domain-model.md)）。如果您的組織把病患或公民記錄為聯絡人，該資料如何分類由**您**決定；計劃是按更嚴格的理解來編寫的（[plan](../../../../spec/plan.md)）。

## 資料流向

| 儲存 | 存放內容 | 儲存庫中的保護措施 |
|---|---|---|
| PostgreSQL | 所有記錄、稽核鏈、破玻璃授權 | 兩列欄位加密；僅追加的稽核觸發器；靜態加密由部署方負責 |
| Redis | 洞察回應快取（30 秒）、限流計數器、破玻璃授權鍵 | 按呼叫者區分鍵；**需要 TLS、密碼，且不對公網暴露** |
| 記錄/指標 | 請求後設資料、Prometheus 指標 | 保留期限由部署方負責 |
| 電子郵件服務商（未來） | 郵件內容和收件人 | 尚未建置（T39） |

## 整合與身份

- 登入來自簽發 PASETO 權杖的身份服務，或 Keycloak。因此入職/調動/離職、多因素認證和會話策略屬於**您的身份提供方**；CRM 只執行權杖所聲明的內容，並拒絕已過期的權杖。
- API 以 OpenAPI 文件化（[gds-api-review](../../../../spec/compliance/gds-api-review.md)），透過請求標頭進行版本管理，使用 `Link` 頭分頁，並以 RFC 9457 問題文件返回錯誤。變更和棄用規則見 [api-lifecycle](../../../../spec/compliance/api-lifecycle.md)。
- CI 會為服務和 UI 生成 SBOM（CycloneDX）；發布工作流會對 SBOM 和映象簽名。

## 仍由您承擔的資訊治理職責

備份與恢復的證據、按表設定的保留計劃、在資料庫之外錨定稽核鏈頭、欄位金鑰的 KMS 保管、與任何供應商的資料處理協議，以及資料保護影響評估（[dpia-template](../../../../spec/compliance/dpia-template.md)）。控制對映（[control-mapping](../../../../spec/compliance/control-mapping.md)）將每項控制標記為“已實現”、“部署方”或“差距”。
