# 최고정보책임자를 위해

> 엔지니어링 브리핑이며, 법률 자문, 인증, 감사가 아닙니다. 2026-10-11 현재 저장소가 보여 주는
> 내용을 서술합니다. 여기의 어떤 내용도 인증 취득을 주장하지 않습니다.

## 정보와 데이터 관점

이 CRM은 **관계 데이터**를 보관합니다. 다른 시스템에 있는 식별자를 감싼 연락처와 계정, 활동, 거래, 티켓, 동의 이력,
감사 로그입니다. 인구 통계 정보는 의도적으로 신원 레지스트리에 남깁니다([domain-model](../../../../spec/domain-model.md)).
귀 조직이 환자나 시민을 연락처로 기록한다면, 그 데이터의 분류는 **귀하가** 결정할 몫입니다. 계획은 더 엄격한 해석에 맞춰
작성되어 있습니다([plan](../../../../spec/plan.md)).

## 데이터가 가는 곳

| 저장소 | 보관 내용 | 저장소 내 보호 |
|---|---|---|
| PostgreSQL | 모든 레코드, 감사 체인, 비상 접근 부여 | 두 열의 필드 암호화, 추가 전용 감사 트리거, 저장 시 암호화는 배포자의 몫 |
| Redis | 인사이트 응답 캐시(30초), 속도 제한 카운터, 비상 접근 부여 키 | 호출자별 키, **TLS, 비밀번호가 필요하며 공개 노출은 안 됨** |
| 로그/지표 | 요청 메타데이터, Prometheus 지표 | 보존은 배포자의 몫 |
| 이메일 제공자(향후) | 메시지 내용과 수신자 | 구현되지 않음 (T39) |

## 통합과 신원

- 로그인은 PASETO 토큰을 발급하는 신원 서비스 또는 Keycloak에서 옵니다. 따라서 입사/이동/퇴사 처리, MFA, 세션 정책은
  **귀사 신원 제공자의 몫**입니다. CRM은 토큰이 말하는 내용을 집행하며 만료된 토큰은 거부합니다.
- API는 OpenAPI로 문서화되어 있고([gds-api-review](../../../../spec/compliance/gds-api-review.md)), 헤더로 버전을 관리하며,
  `Link` 헤더로 페이지를 나누고, 오류를 RFC 9457 문제 문서로 반환합니다. 변경 및 지원 중단 규칙은
  [api-lifecycle](../../../../spec/compliance/api-lifecycle.md)에 있습니다.
- 서비스와 UI의 SBOM(CycloneDX)은 CI에서 생성됩니다. 릴리스 워크플로는 이를 이미지와 함께 서명합니다.

## 귀하에게 남는 정보 거버넌스 의무

백업과 복원의 증거, 테이블별 보존 일정, 감사 체인 헤드를 데이터베이스 밖에 고정하기, 필드 키의 KMS 보관, 모든 공급업체와의
데이터 처리 계약, 그리고 데이터 보호 영향 평가([dpia-template](../../../../spec/compliance/dpia-template.md))입니다. 통제
매핑([control-mapping](../../../../spec/compliance/control-mapping.md))은 각 통제를 Implemented, Deployer, Gap 중 하나로
표시합니다.
