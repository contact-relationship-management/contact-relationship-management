# 최고법무책임자를 위해

> 엔지니어링 브리핑이며, 법률 자문, 인증, 감사가 아닙니다. 2026-10-11 현재 저장소가 보여 주는
> 내용을 서술합니다. 여기의 어떤 내용도 인증 취득을 주장하지 않습니다.

## 법적 입장 요약

저장소는 **운영 환경에 쓸 준비가 되어 있지 않으며** 합성 데이터를 보관합니다. 어떤 체제에 대한 규정 준수도 주장하지
않습니다. 여러 체제를 뒷받침하는 기술 기능을 구현하고, 배포자가 추가해야 하는 것을 열거합니다
([regulatory](../../../../spec/regulatory.md)).

## 관련되는 체제

| 체제 | 소프트웨어가 뒷받침하는 것 | 귀하가 마련해야 하는 것 |
|---|---|---|
| UK/EU GDPR | 동의 이력, 정보 주체 열람 내보내기, 삭제(열린 의무가 있는 동안은 거부), 보존 정리, 데이터 최소화, 열람 감사 | 목적별 적법 근거, DPIA([템플릿](../../../../spec/compliance/dpia-template.md)), 처리 기록, 보존 일정, 컨트롤러/프로세서 역할 |
| PECR / e-privacy | 동의가 있어야 하는 발송, 즉시 수신 거부 | 실제 발송자를 위한 발송자 식별과 소프트 옵트인 결정 |
| HIPAA (미국 의료 데이터인 경우) | 감사 통제, 접근 통제, 무결성, 전송 보안 기능 | 비즈니스 어소시에이트 계약, 위험 분석, 정책, 인력 교육. 이 소프트웨어가 귀하를 준수 상태로 만들어 주지는 않습니다 |
| NHS DTAC / DCB0129/0160 | 증거 초안([dtac-supporting](../../../../spec/compliance/dtac-supporting.md)) | 지명된 임상 안전 책임자, 위험 요인 로그, 인증. 평가에 따르면 DTAC는 아마도 적용되지 않습니다 |
| 접근성 (WCAG 2.2 AA, 공공 부문) | 자동 검사와 정직한 성명 | 규정 준수를 주장하기 전에 수동 감사(T48) |
| 정부 보안 (NIST 800-53, ISO 27001, Cyber Essentials) | 통제 매핑([control-mapping](../../../../spec/compliance/control-mapping.md)) | 인증과 독립적인 보증 |

## 아직 존재하지 않지만 필요하게 될 계약

1. 이메일 제공자와의 데이터 처리 계약 및 국제 전송 조건 (T39).
2. 침투 테스트 업체와의 작업 명세서와 기밀 유지 조건 (T42).
3. PostgreSQL, Redis, 로그에 대한 호스팅 및 하위 처리자 조건.
4. 라이선스: [LICENSE.md](../../../../LICENSE.md)를 참고하세요. 저장소에는 보안, 거버넌스, AI 사용 성명도 있습니다.

## 구체적인 법적 주의 사항

- **삭제**는 연락처를 익명화하며, 열린 거래, 티켓 또는 활성 육성 등록이 있는 동안은 거부됩니다. 감사 체인은 행위의 기록을
  보존하므로, 이것이 삭제 요청과 어떻게 맞물리는지는 DPIA에서 정리하세요.
- 가려진 데이터에 대한 **비상 접근** 열람은 귀하가 문서화한 근거에 따를 때만 적법합니다. 사유 필드는 증거이지 권한이
  아닙니다.
- 리드의 **점수화**: 사람에 대한 중요한 결정에 영향을 주게 된다면 자동화된 의사 결정 규정이 적용됩니다
  ([regulatory](../../../../spec/regulatory.md)).
- **API 약속:** [api-lifecycle](../../../../spec/compliance/api-lifecycle.md)은 API 변경을 제거하기 전에 180일의 예고 기간을
  둡니다. 이는 유지관리자의 선택입니다. 고객이 이에 의존하게 된다면 계약에 포함할지 결정하세요.
- **공개 주장:** 규정 준수, 인증, 승인을 주장하지 마세요.
