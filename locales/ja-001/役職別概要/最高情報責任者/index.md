# 最高情報責任者向け

> 技術者向けの概要であり、法的助言、認証、監査ではありません。2026-10-11 時点でリポジトリが
> 示している内容を述べたものです。ここでは認定を主張するものは何もありません。

## 情報とデータの見方

この CRM が保持するのは**関係性のデータ**です。具体的には、他のシステムで管理されている識別子を包む連絡先と
アカウント、活動、ディール、チケット、同意の履歴、監査ログです。属性情報は意図的に ID レジストリに残されます
([domain-model](../../../../spec/domain-model.md))。組織が患者や市民を連絡先として記録する場合、そのデータの
分類を決めるのは**あなた**です。計画は、より厳格な解釈に沿って書かれています([plan](../../../../spec/plan.md))。

## データの行き先

| ストア | 保持するもの | リポジトリ内の保護 |
|---|---|---|
| PostgreSQL | すべてのレコード、監査チェーン、ブレークグラスの付与 | 2 つの列のフィールド暗号化、追記専用の監査トリガー。保存時の暗号化は導入者の担当 |
| Redis | インサイト応答のキャッシュ(30 秒)、レート制限カウンター、ブレークグラス付与キー | 呼び出し元ごとにキー付け。**TLS、パスワード、公開しないことが必要** |
| ログ/メトリクス | リクエストのメタデータ、Prometheus メトリクス | 保持は導入者の担当 |
| メールプロバイダー(将来) | メッセージの内容と宛先 | 未構築(T39) |

## 連携と ID

- サインインは、PASETO トークンを発行する ID サービス、または Keycloak から行われます。そのため、入社、異動、
  退社の処理、MFA、セッションのポリシーは**ご利用の ID プロバイダーの**担当です。CRM はトークンが示す内容を強制し、
  期限切れのものを拒否します。
- API は OpenAPI で文書化され([gds-api-review](../../../../spec/compliance/gds-api-review.md))、
  ヘッダーでバージョン管理され、`Link` ヘッダーでページ分割され、エラーは RFC 9457 の問題ドキュメントとして
  返されます。変更と廃止の規則は [api-lifecycle](../../../../spec/compliance/api-lifecycle.md) にあります。
- サービスと UI の SBOM(CycloneDX)は CI で生成され、リリースワークフローがそれらとイメージに署名します。

## あなたに残る情報ガバナンス上の責務

バックアップと復元の証拠、テーブルごとの保持スケジュール、監査チェーンの先頭をデータベース外に固定すること、
フィールド鍵の KMS による保管、あらゆる供給者とのデータ処理契約、そしてデータ保護影響評価
([dpia-template](../../../../spec/compliance/dpia-template.md))。統制の対応表
([control-mapping](../../../../spec/compliance/control-mapping.md))は、各統制を「実装済み」、「導入者」、
「ギャップ」のいずれかで示しています。
