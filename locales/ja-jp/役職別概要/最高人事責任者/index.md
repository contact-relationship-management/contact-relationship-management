# 最高人事責任者向け

> 技術者向けの概要であり、法的助言、認証、監査ではありません。2026-10-11 時点でリポジトリが
> 示している内容を述べたものです。ここでは認定を主張するものは何もありません。

## この製品で人が重要な理由

個人データへのアクセスは、ロールによって決まります。ソフトウェアは、その人のトークンが示す内容を強制します。
しかし、**誰にどのロールを与え、いつ外すかは人に関するプロセス**であり、このリポジトリが代わりに行うことは
できません。

## ソフトウェアがあなたのプロセスに提供するもの

- **ロールに基づく可視性:** 一部のロールには、連絡チャネル、ディール金額、金額に関するビューがマスクされて
  表示されます。マネージャー、管理者、サービス層にはより多くが表示されます([auth](../../../../spec/auth.md))。
- **監査される読み取り:** 個人データを読むと、その人の名前を記した記録が残ります。本稼働の前に、
  職員にこのことを伝えてください。
- **緊急アクセス:** 理由を示して最長 60 分間、読み取り権限を昇格できます。事後に別の人が必ずレビューします。
  両方の立場の人を訓練してください。
- **アイドル時のサインアウト:** ブラウザーで 15 分後に実行されます。
- **アクセシビリティ:** 公開声明と自動チェックがあります。手動監査(T48)には、障害のある利用者と
  支援技術のテスト担当者がなお必要です。
- **言語:** UI は 8 つのロケールに翻訳されています。翻訳は母語話者によるレビューを**受けていません**。

## あなたの責任

| 領域 | 対応 |
|---|---|
| 入社、異動、退社 | ID プロバイダーを通じてロールを付与および削除します。CRM は期限切れのトークンを拒否しますが、アカウントは管理しません |
| 研修 | データ保護、同意の規則、ブレークグラスの利用とレビュー、アクセシブルな実践 |
| ポリシー | 許容される使い方、監視の通知(読み取りは監査されます)、緊急アクセスの不正利用に対する懲戒の手順 |
| レビュー担当の体制 | ブレークグラスの付与を誰がレビューするか、その人が不在のときの代行者を指名します |
| 採用 | プログラムに必要なロール: 独立テスト担当との窓口、NHS の対象範囲であれば臨床安全責任者、データ保護の責任者、アクセシビリティの責任者 |
| ウェルビーイング | 機微な案件を扱う職員への支援。CRM はケース管理システムではありませんが、機微な関係性のデータを保持することがあります |

## 人の手が必要な未了事項

支援技術の利用者による手動のアクセシビリティ監査(T48)、母語話者による翻訳レビュー、そして上記の
レビューとアラートの責務の担当者決定。[tasks.md](../../../../spec/tasks.md) を参照してください。
