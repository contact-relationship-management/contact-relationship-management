# Для директора по персоналу

> Инженерная справка, а не юридическая консультация, сертификация или аудит. В ней изложено,
> что показывает репозиторий по состоянию на 2026-10-11. Ничто здесь не утверждает наличие аккредитации.

## Почему люди важны для этого продукта

Доступ к персональным данным определяется ролью. Программа применяет то, что сказано в токене человека; **кто получает
какую роль и когда её лишается — это кадровый процесс**, который этот репозиторий не может выполнить за вас.

## Что программа даёт вашим процессам

- **Видимость по ролям:** некоторые роли видят скрытые значения каналов связи, сумм сделок и денежных представлений;
  руководители, администраторы и служебные уровни видят больше ([auth](../../../../spec/auth.md)).
- **Аудируемые чтения:** чтение персональных данных оставляет след с именем человека. Сотрудников следует предупредить
  об этом до запуска.
- **Экстренный доступ:** человек может получить обоснованное повышение прав на чтение до 60 минут; другой человек
  должен проверить его впоследствии. Обучите обе стороны.
- **Выход при бездействии** через 15 минут в браузере.
- **Доступность:** публичное заявление и автоматические проверки; для ручного аудита (T48) всё ещё нужны пользователи с
  инвалидностью и тестировщики вспомогательных технологий.
- **Языки:** интерфейс переведён на 8 локалей; переводы **не** проверялись носителями языка.

## Ваши обязанности

| Область | Действие |
| --- | --- |
| Приём, перемещение, увольнение | Выдавайте и отзывайте роли через своего поставщика идентификации; CRM отклоняет просроченные токены, но не управляет учётными записями |
| Обучение | Защита данных, правила согласия, использование и проверка экстренного доступа, доступные практики |
| Политики | Допустимое использование, уведомление о мониторинге (чтения аудируются), дисциплинарный порядок при злоупотреблении экстренным доступом |
| Возможности проверяющих | Назначьте, кто проверяет разрешения экстренного доступа, и кто заменяет его в отсутствие |
| Подбор персонала | Роли, нужные программе: контакт с независимым тестировщиком, специалист по клинической безопасности (если применимо NHS), ответственный за защиту данных, ответственный за доступность |
| Благополучие | Поддержка сотрудников, работающих с чувствительными случаями; CRM не является системой ведения дел, но может хранить чувствительные данные об отношениях |

## Открытые пункты, требующие людей

Ручной аудит доступности с пользователями вспомогательных технологий (T48), проверка переводов носителями языка и
распределение ответственности за описанные выше обязанности по проверке и оповещению. См. [tasks.md](../../../../spec/tasks.md).
