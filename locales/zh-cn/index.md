# 联系人关系管理

面向销售、营销和客户支持的开源 CRM 软件。

联系人关系管理用于跟踪销售、营销和支持环节中与客户及潜在客户的关系。系统为每位联系人保留一条记录，并要求在发送消息前已记录同意。本软件尚未准备好用于生产环境，使用合成数据运行。

## 优势

- **统一的联系人记录。** 销售、营销、支持和分析使用同一条记录。
- **已记录的同意。** 未记录同意的联系人不会收到任何内容。每封电子邮件都包含经过签名的退订链接。
- **减少个人数据。** CRM 存储的是对身份服务中某个人的引用，而不是姓名或地址的副本。
- **结果可解释。** 潜在客户评分依据可读的规则计算，预测依据加权的销售管道阶段计算。
- **国际化设计。** 姓名、地址、日历和书写方向不受单一国家格式的限制。界面提供八种语言。
- **公开的规范。** 规范、代码和测试均已公开。文档说明了哪些功能已实现、哪些尚未实现。

## 功能

- **销售。** 基于规则的潜在客户评分、看板式交易管道和按阶段加权的预测。
- **营销。** 细分营销活动和培育序列。除非配置邮件模式，否则发送为模拟操作。
- **支持。** 带优先级和服务级别截止时间的工单，以及知识库文章。
- **分析。** 用于查看赢单率、各阶段管道、营销活动回报、服务级别状况和客户终身价值的仪表板。
- **数据质量。** 按概率检测重复记录，支持合并和撤销。
- **治理。** 审计日志、基于角色的访问控制，以及对数据主体访问和删除请求的支持。

## 入门

1. **获取代码。** 克隆仓库。需要 Node.js 和 pnpm。
2. **启动应用。** 在 Svelte 目录中运行 `pnpm install`，然后运行 `pnpm dev`。
3. **登录。** 使用 `example@example.com`。不需要其他服务。
4. **查看导览。** 导览使用虚构数据，涵盖联系人、潜在客户、交易、营销活动、工单和管理层视图。

[教程](../../docs/tutorial-first-tour.md)（英文）说明了每个步骤。[安装和使用](../../INSTALL.md)（英文）介绍完整服务。
