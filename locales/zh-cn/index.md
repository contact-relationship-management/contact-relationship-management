# 联系人关系管理

销售、营销和支持汇聚一处，亲切易用，同意为先。

欢迎！联系人关系管理把与您合作的人，以及您对他们的每一项承诺，集中到每位联系人的一条记录上。这是开源的演示软件，您可以用虚构数据自由探索，并了解它的具体工作方式。

## 为什么值得一看

- **每位客户一幅完整图景。** 销售、营销、支持和分析共用同一条记录，谁都不必从头开始沟通。
- **同意为先。** 没有已记录的同意，就不会向联系人发送任何内容；电子邮件附带经过签名的退订链接。
- **需要保护的个人数据更少。** CRM 保存的是对身份服务中某个人的引用，而不是其姓名或地址的副本。
- **决策可以解释。** 潜在客户评分来自您能读懂的规则，预测来自加权阶段，所以您总能回答“为什么是这个数字？”
- **面向全世界。** 姓名、地址、日历和书写方向都不以某一个国家的形式为准，界面提供八种语言。
- **自始至终开放。** 规范、代码和测试全部公开，文档如实说明哪些已经实现、哪些尚未实现。

## 您可以用它做什么

- **销售。** 用清晰的规则为潜在客户评分，在看板上推进交易，并按加权阶段进行预测。
- **营销。** 向细分人群开展营销活动，逐步培育联系人；在您启用真实邮件之前，发送都是模拟的。
- **支持。** 按优先级和截止时间跟踪工单，并发布知识库文章。
- **洞察。** 在仪表板上查看赢单率、各阶段销售管道、营销活动回报、服务健康状况和客户终身价值。
- **保持记录整洁。** 用可以查看的概率找出可能的重复记录，合并它们，也可以撤销合并。
- **保持可问责。** 保留审计日志，按角色控制访问，并响应数据主体访问和删除请求。

## 四步开始试用

1. **获取代码。** 克隆仓库。您需要 Node.js 和 pnpm。
2. **启动应用。** 在 Svelte 文件夹中运行 `pnpm install`，然后运行 `pnpm dev`。
3. **登录。** 使用 `example@example.com`。不需要其他服务。
4. **参加导览。** 用虚构数据依次浏览联系人、潜在客户、交易、营销活动、工单和管理层视图。

这是演示软件，不是生产级 CRM。请使用合成数据。除非您配置真实的邮件模式，否则不会发送真实邮件；此处的法律或合规措辞不构成法律建议。
