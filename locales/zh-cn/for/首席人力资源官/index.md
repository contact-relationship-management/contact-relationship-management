# 致首席人力资源官

> 工程简报，不是法律意见、认证或审计。内容反映截至 2026-10-11 代码仓库所显示的情况。本文不声称已获得任何认可。

## 为什么人对这个产品很重要

对个人数据的访问由角色决定。软件会执行一个人的令牌所声明的内容；**谁获得哪个角色、何时被收回，是一项人员流程**，这是仓库无法替您完成的。

## 软件为您的流程提供了什么

- **基于角色的可见性：** 部分角色看到的联系渠道、交易金额和资金视图是脱敏的；经理、管理员和服务层级可以看到更多（[auth](../../../../spec/auth.md)）。
- **被审计的读取：** 读取个人数据会留下点名到具体人员的轨迹。应在上线前告知员工。
- **紧急访问：** 一个人可以获得最长 60 分钟、需说明理由的读取提权；事后必须由另一个人审查。两方都需要培训。
- **空闲登出：** 浏览器中空闲 15 分钟后登出。
- **无障碍：** 有公开声明和自动化检查；人工审计（T48）仍然需要残障用户和辅助技术测试人员。
- **语言：** 界面已翻译为 8 种语言区域；这些译文**尚未**经过母语者审阅。

## 您的职责

| 领域 | 行动 |
|---|---|
| 入职、调动、离职 | 通过您的身份提供方授予和收回角色；CRM 会拒绝过期令牌，但不管理账户 |
| 培训 | 数据保护、同意规则、破玻璃的使用与审查、无障碍实践 |
| 政策 | 可接受使用、监控告知（读取会被审计）、对滥用紧急访问的纪律处理途径 |
| 审查人员的能力 | 指定谁来审查破玻璃授权，以及其不在时的代理人 |
| 招聘 | 项目所需的角色：独立测试联络人、属于 NHS 范围时的临床安全官、数据保护负责人、无障碍负责人 |
| 员工关怀 | 为处理敏感个案的员工提供支持；CRM 不是个案管理系统，但可能保存敏感的关系数据 |
