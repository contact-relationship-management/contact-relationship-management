# 通往生产环境之路

> 联系人关系管理尚未准备好用于生产环境。本页说明这里所说的生产环境是什么意思，以及各部分进展到了什么程度。

本软件使用合成数据运行。除非配置了真实的邮件模式，否则邮件为模拟发送。请勿在其中放入真实的个人数据。

## 生产环境的含义

生产部署保存真实人员的数据，并向他们发送真实消息。对本项目而言，这需要具备以下全部条件：

- **真实登录。** 每个请求都经过认证，访问规则与部署组织的角色一致。
- **合法发送。** 每条消息都有已记录的同意，并在其发送目的地的每一处法律下具有合法依据，且经由能够处理退信、投诉和退订的真实邮件服务商发送。
- **独立保证。** 项目以外的人员已测试安全性和无障碍性，发现的问题已修复或已被接受。
- **运维。** 已实际恢复过的备份、监控、事件处理流程，以及值班人员。
- **稳定性证据。** 在与部署环境相似的硬件上、在真实负载下长时间运行，没有错误或变慢。

生产就绪由每个部署分别判定。部署方只能为其自身组织和收件人关闭部分关卡。本页所依据的工程评估是 [spec/plan.md](../../../spec/plan.md)。未关闭的关卡见 [spec/tasks.md](../../../spec/tasks.md)。

## 就绪度

每个百分比都是 2026-11-13 根据任务清单作出的估计，而非测量结果。

- **认证与访问控制** (70%): 已构建通过 PASETO 令牌或 Keycloak/OIDC 登录、带记录级检查的基于属性的访问规则，以及未启用认证即拒绝启动的生产模式。尚无真实部署以其自身属性启用它们，执行矩阵也尚未覆盖所有处理程序（CRM-G1）。
- **邮件投递** (40%): 默认使用模拟发送器，另有一个 SMTP 发送器。尚无带退信和投诉 webhook 或抑制列表的邮件服务商适配器（CRM-T39）。
- **数据保护与电子营销法律** (15%): 已构建同意记录、数据访问、删除和保留。尚未为本项目研读任何地区的法律，对真实发送路径的审查仍未完成（CRM-G2，[regulatory](../../../spec/regulatory.md)）。
- **独立安全保证** (10%): 已编写渗透测试范围。尚未进行渗透测试、正式风险分析或认证（CRM-T42）。AI 安全审计不属于独立保证。
- **无障碍** (50%): 针对 WCAG 2.2 A 和 AA 的 axe-core 自动检查在每个页面路由上均通过。尚未进行仅用键盘、使用屏幕阅读器或 400% 缩放的人工审核（CRM-T48）。
- **翻译** (30%): 界面提供八种语言。英语以外的文字由机器撰写，尚无母语使用者审阅。
- **运维** (30%): 运维手册涵盖备份与恢复、密钥管理、静态加密、事件响应和日志保留。尚未测试过任何恢复，手册中的上线检查清单仍未完成。
- **性能与稳定性** (20%): 已有负载测试和一项长时间稳定性测试。稳定性测试已在演示环境上运行两分钟；尚无长时间运行，也没有在类生产硬件上的基线。
- **发布完整性** (85%): 发布镜像为多架构，已签名并附有证明，签名可以验证。Actions 和镜像按摘要固定，历史记录会扫描密钥。尚未检查已拉取发布镜像的 amd64 部分，也还没有第二个代码托管平台（CRM-T192）。
- **持续集成** (60%): 一个脚本运行所有检查，在 GitHub Actions 和 Woodpecker 上均是如此。覆盖率下限、定期变异测试和其他关卡仍未完成（CRM-T94）。
- **演示保护措施** (60%): 每位导览访客都会获得一份独立的演示数据副本，最多 200 份。除非设置 `CRM_DEMO_TOUR=off`，导览仍默认开启（CRM-T92）。

## 本页如何维护

当某个关卡关闭时，请在包含该工作的同一提交中更改估计值及其依据，并链接相应任务。
