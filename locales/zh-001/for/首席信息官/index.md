# 致首席信息官

> 工程简报，不是法律意见、认证或审计。内容反映截至 2026-10-11 代码仓库所显示的情况。本文不声称已获得任何认可。

## 信息与数据视角

这个 CRM 保存的是**关系数据**：联系人和账户（对其他系统中所持标识符的封装）、活动、交易、工单、同意历史和审计日志。人口统计信息被有意保留在身份注册系统中（[domain-model](../../../../spec/domain-model.md)）。如果您的组织把患者或公民记录为联系人，该数据如何分类由**您**决定；计划是按更严格的理解来编写的（[plan](../../../../spec/plan.md)）。

## 数据流向

| 存储 | 存放内容 | 仓库中的保护措施 |
|---|---|---|
| PostgreSQL | 所有记录、审计链、破玻璃授权 | 两列字段加密；仅追加的审计触发器；静态加密由部署方负责 |
| Redis | 洞察响应缓存（30 秒）、限流计数器、破玻璃授权键 | 按调用者区分键；**需要 TLS、密码，且不对公网暴露** |
| 日志/指标 | 请求元数据、Prometheus 指标 | 保留期限由部署方负责 |
| 电子邮件服务商（未来） | 邮件内容和收件人 | 尚未构建（T39） |

## 集成与身份

- 登录来自签发 PASETO 令牌的身份服务，或 Keycloak。因此入职/调动/离职、多因素认证和会话策略属于**您的身份提供方**；CRM 只执行令牌所声明的内容，并拒绝已过期的令牌。
- API 以 OpenAPI 文档化（[gds-api-review](../../../../spec/compliance/gds-api-review.md)），通过请求头进行版本管理，使用 `Link` 头分页，并以 RFC 9457 问题文档返回错误。变更和弃用规则见 [api-lifecycle](../../../../spec/compliance/api-lifecycle.md)。
- CI 会为服务和 UI 生成 SBOM（CycloneDX）；发布工作流会对 SBOM 和镜像签名。

## 仍由您承担的信息治理职责

备份与恢复的证据、按表设定的保留计划、在数据库之外锚定审计链头、字段密钥的 KMS 保管、与任何供应商的数据处理协议，以及数据保护影响评估（[dpia-template](../../../../spec/compliance/dpia-template.md)）。控制映射（[control-mapping](../../../../spec/compliance/control-mapping.md)）将每项控制标记为“已实现”、“部署方”或“差距”。
