# 致首席法务官

> 工程简报，不是法律意见、认证或审计。内容反映截至 2026-10-11 代码仓库所显示的情况。本文不声称已获得任何认可。

## 法律立场简述

该仓库是**使用合成数据的演示软件**。它不声称符合任何制度。它实现了支持若干制度的技术功能，并列出了部署方必须补充的内容（[regulatory](../../../../spec/regulatory.md)）。

## 涉及的制度

| 制度 | 软件提供的支持 | 您必须提供的内容 |
|---|---|---|
| 英国/欧盟 GDPR | 同意历史、主体访问导出、删除（存在未了结义务时被拒绝）、保留清理、数据最小化、读取审计 | 每项处理目的的合法依据、DPIA（[模板](../../../../spec/compliance/dpia-template.md)）、处理活动记录、保留计划、控制者/处理者角色 |
| PECR / 电子隐私 | 以同意为条件的发送、即时退订 | 真实发送方的发件人身份标识和软性选择加入（soft opt-in）的决定 |
| HIPAA（如涉及美国健康数据） | 审计控制、访问控制、完整性、传输安全功能 | 商业伙伴协议（BAA）、风险分析、政策、员工培训。该软件不会让您自动合规 |
| NHS DTAC / DCB0129/0160 | 证据草稿（[dtac-supporting](../../../../spec/compliance/dtac-supporting.md)） | 指定的临床安全官、危害日志、认证。评估认为 DTAC 很可能不适用 |
| 无障碍（WCAG 2.2 AA，公共部门） | 自动化检查和如实的声明 | 在作出任何合规声明之前进行人工审计（T48） |
| 政府安全（NIST 800-53、ISO 27001、Cyber Essentials） | 控制映射（[control-mapping](../../../../spec/compliance/control-mapping.md)） | 认证和独立保证 |

## 您需要但尚不存在的合同

1. 与电子邮件服务商的数据处理协议和跨境传输条款（T39）。
2. 与渗透测试机构的工作说明书和保密条款（T42）。
3. PostgreSQL、Redis 和日志的托管及子处理者条款。
4. 许可证：见 [LICENSE.md](../../../../LICENSE.md)；仓库还附有安全、治理和 AI 使用声明。

## 具体的法律注意事项

- **删除**会将联系人匿名化，并在存在未结交易、工单或有效的培育登记（nurture enrolment）时被拒绝；审计链会保留操作记录，因此请在您的 DPIA 中说明这与删除请求之间的关系。
- 对已脱敏数据的**破玻璃**读取，只有在您记录在案的依据之上才合法；理由字段是证据，而不是授权。
- 线索**评分**：如果它将来影响对个人的重大决定，则适用自动化决策规则（[regulatory](../../../../spec/regulatory.md)）。
- **公开声明：** 不要声称合规、认证或获得批准。
