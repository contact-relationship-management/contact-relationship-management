# چیف لیگل آفیسر کے لیے

> انجینئرنگ بریفنگ، نہ قانونی مشورہ، نہ تصدیق اور نہ آڈٹ۔ یہ بتاتی ہے کہ
> ریپوزٹری 2026-10-11 تک کیا دکھاتی ہے۔ یہاں کچھ بھی منظوری کا دعویٰ نہیں کرتا۔

## قانونی پوزیشن مختصراً

ریپوزٹری **پیداواری استعمال کے لیے تیار نہیں** ہے اور مصنوعی ڈیٹا رکھتی ہے۔ یہ کسی نظام کی تعمیل کا دعویٰ نہیں کرتی۔ یہ ایسی تکنیکی
خصوصیات نافذ کرتی ہے جو کئی نظاموں کی معاونت کرتی ہیں، اور بتاتی ہے کہ تعینات کرنے والے کو کیا شامل کرنا ہوگا
([regulatory](../../../../spec/regulatory.md))۔

## متعلقہ قانونی نظام

| نظام | سافٹ ویئر کیا معاونت کرتا ہے | آپ کو کیا فراہم کرنا ہوگا |
|---|---|---|
| UK/EU GDPR | رضامندی کی تاریخ، ذاتی ڈیٹا تک رسائی کی برآمد، مٹانا (کھلی ذمہ داریاں ہوں تو مسترد)، برقرار رکھنے کی صفائی، ڈیٹا میں کمی، پڑھنے کا آڈٹ | ہر مقصد کے لیے قانونی بنیاد، DPIA ([ٹیمپلیٹ](../../../../spec/compliance/dpia-template.md))، پروسیسنگ کے ریکارڈ، برقرار رکھنے کا شیڈول، کنٹرولر/پروسیسر کے کردار |
| PECR / ای پرائیویسی | رضامندی سے مشروط ترسیل، فوری رکنیت ختم کرنا | حقیقی بھیجنے والے کے لیے بھیجنے والے کی شناخت اور نرم رضامندی کے فیصلے |
| HIPAA (اگر امریکی صحت کا ڈیٹا ہو) | آڈٹ کنٹرولز، رسائی کا کنٹرول، سالمیت، ترسیل کی سیکیورٹی کی خصوصیات | کاروباری ساتھی کا معاہدہ، خطرے کا تجزیہ، پالیسیاں، عملے کی تربیت۔ سافٹ ویئر آپ کو تعمیل کرنے والا نہیں بناتا |
| NHS DTAC / DCB0129/0160 | شواہد کے مسودات ([dtac-supporting](../../../../spec/compliance/dtac-supporting.md)) | نامزد کلینیکل سیفٹی افسر، خطرات کا لاگ، سرٹیفیکیشنز۔ جائزے کے مطابق DTAC غالباً لاگو نہیں ہوتا |
| رسائی پذیری (WCAG 2.2 AA، سرکاری شعبہ) | خودکار جانچیں اور ایک دیانت دارانہ بیان | تعمیل کے کسی بھی دعوے سے پہلے دستی آڈٹ (T48) |
| حکومتی سیکیورٹی (NIST 800-53، ISO 27001، Cyber Essentials) | کنٹرول کی نقشہ بندی ([control-mapping](../../../../spec/compliance/control-mapping.md)) | سرٹیفیکیشن اور آزاد یقین دہانی |

## وہ معاہدے جن کی آپ کو ضرورت ہوگی اور جو ابھی موجود نہیں

1. ای میل فراہم کنندہ کے ساتھ ڈیٹا پروسیسنگ کا معاہدہ اور بین الاقوامی منتقلی کی شرائط (T39)۔
2. دخول ٹیسٹ کرنے والی فرم کے ساتھ کام کا بیان اور رازداری کی شرائط (T42)۔
3. PostgreSQL، Redis اور لاگز کے لیے میزبانی اور ذیلی پروسیسر کی شرائط۔
4. لائسنس: [LICENSE.md](../../../../LICENSE.md) دیکھیں؛ ریپوزٹری میں سیکیورٹی، نظم و نسق اور AI کے استعمال کے بیانات بھی ہیں۔

## قانونی توجہ طلب نکات

- **مٹانا** رابطے کو گمنام بناتا ہے اور اگر کوئی کھلی ڈیل، ٹکٹ یا فعال نگہداشتی اندراج موجود ہو تو مسترد ہو جاتا ہے؛ آڈٹ چین اقدامات کے
  ریکارڈ رکھتی ہے، اس لیے اپنے DPIA میں طے کریں کہ یہ مٹانے کی درخواستوں سے کیسے تعامل کرتی ہے۔
- **بریک گلاس** کے ذریعے چھپی ہوئی اقدار پڑھنا صرف آپ کی دستاویزی بنیاد پر قانونی ہے؛ وجہ کا خانہ ثبوت ہے، اختیار نہیں۔
- **اسکورنگ** لیڈز کی: اگر یہ کبھی لوگوں کے بارے میں اہم فیصلوں پر اثر ڈالے تو خودکار فیصلوں کے اصول لاگو ہوتے ہیں
  ([regulatory](../../../../spec/regulatory.md))۔
- **API کے وعدے:** [api-lifecycle](../../../../spec/compliance/api-lifecycle.md) API کی کسی تبدیلی کو ہٹانے سے پہلے 180 دن کی اطلاعی
  مدت طے کرتا ہے۔ یہ دیکھ بھال کرنے والے کا انتخاب ہے؛ اگر صارفین اس پر انحصار کریں گے تو طے کریں کہ کیا یہ معاہدے میں شامل ہونا چاہیے۔
- **عوامی دعوے:** تعمیل، سرٹیفیکیشن یا منظوری کا بیان نہ دیں۔
