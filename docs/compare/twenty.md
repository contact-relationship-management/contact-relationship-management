# Contact Relationship Management and Twenty

Twenty is an open-source CRM with a hosted option. Contact Relationship Management is open-source demo software, not a production CRM, so this is a fair look at two different things rather than a contest.

## At a glance

| | Twenty | Contact Relationship Management |
| --- | --- | --- |
| What it is | An open-source CRM, described as "the open alternative to Salesforce, designed for AI" | Open-source demo software, driven by its specification |
| Licence | Mostly AGPLv3, with some commercially licensed files and some MIT packages | MIT, Apache-2.0, BSD-3-Clause, GPL-2.0-only or GPL-3.0-only, at your option |
| Where it runs | Hosted at twenty.com, or on your own infrastructure with Docker Compose | You run it yourself: a Rust service, a Svelte interface and PostgreSQL |
| Focus | A CRM whose objects, views, workflows and agents can be extended as code | Sales, marketing, support and analytics, with consent first |

## Where Twenty is stronger

- It is a full product, with a hosted service if you do not want to run it; this project is a smaller demo.
- It is designed to be extended as code, including with AI agents.
- You can choose hosted or self-hosted use.

## Where this project is different

- This project is driven by its specification, which is the single source of truth.
- Its licences are permissive: you may choose MIT, Apache-2.0 or BSD-3-Clause as well as GPL.
- It keeps a reference to a person rather than a copy of their details, and puts consent first.

## Which suits you

- Choose Twenty if you want a modern open-source CRM to use in your business.
- Try this project if you want a compact, specification-driven reference to study.
