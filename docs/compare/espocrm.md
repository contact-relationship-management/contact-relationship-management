# Contact Relationship Management and EspoCRM

EspoCRM is a free, open-source CRM written in PHP. Contact Relationship Management is open-source demo software, not a production CRM, so this is a fair look at two different things rather than a contest.

## At a glance

| | EspoCRM | Contact Relationship Management |
| --- | --- | --- |
| What it is | A free, open-source CRM platform | Open-source demo software, driven by its specification |
| Licence | GNU AGPLv3 | MIT, Apache-2.0, BSD-3-Clause, GPL-2.0-only or GPL-3.0-only, at your option |
| Where it runs | Self-hosted by script, by hand or with Docker | You run it yourself: a Rust service, a Svelte interface and PostgreSQL |
| Focus | Leads, contacts, sales, marketing and support cases | Sales, marketing, support and analytics, with consent first |

## Where EspoCRM is stronger

- It has broader features; this project is a demo.
- It is a working product with an online demo, so you can try it without installing anything.
- It supports MySQL, MariaDB and PostgreSQL.

## Where this project is different

- This project puts explainable rules first: scoring and forecasting are meant to be read.
- It is built in Rust and Svelte, with a specification as its source of truth.
- It keeps a reference to a person rather than a copy of their details.

## Which suits you

- Choose EspoCRM if you want a broad open-source CRM on a familiar PHP stack.
- Try this project if you want a small reference with explainable rules.
