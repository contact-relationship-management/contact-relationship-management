# Contact Relationship Management and EspoCRM

EspoCRM is a free, open-source CRM written in PHP. Contact Relationship Management is open-source software that is not ready for production ([path to production](../../locales/en-us/path-to-production/index.md)). The two are not direct alternatives.

## Summary

| | EspoCRM | Contact Relationship Management |
| --- | --- | --- |
| Category | Free, open-source CRM platform | Open-source demonstration software, driven by its specification |
| Licence | GNU AGPLv3 | MIT, Apache-2.0, BSD-3-Clause, GPL-2.0-only or GPL-3.0-only, at the user's option |
| Hosting | Self-hosted by script, by hand or with Docker | Self-hosted: a Rust service, a Svelte interface and PostgreSQL |
| Focus | Leads, contacts, sales, marketing and support cases | Sales, marketing, support and analytics, with recorded consent |

## Where EspoCRM is stronger

- Broader features. This project is a demonstration.
- Working product with an online demo that requires no installation.
- Supports MySQL, MariaDB and PostgreSQL.

## Where this project differs

- Emphasizes explainable rules for scoring and forecasting.
- Built in Rust and Svelte, with the specification as the source of truth.
- Stores a reference to a person, not a copy of their details.

## Suitability

- EspoCRM suits organizations that need a broad open-source CRM on a PHP stack.
- This project suits a small reference with explainable rules.
