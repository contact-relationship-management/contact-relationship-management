# Contact Relationship Management and Zoho CRM

Zoho CRM is a commercial CRM with a free edition. Contact Relationship Management is open-source demo software, not a production CRM, so this is a fair look at two different things rather than a contest.

## At a glance

| | Zoho CRM | Contact Relationship Management |
| --- | --- | --- |
| What it is | A CRM that pairs automation with an approachable design | Open-source demo software, driven by its specification |
| Licence | Commercial, with a free edition for a few users | MIT, Apache-2.0, BSD-3-Clause, GPL-2.0-only or GPL-3.0-only, at your option |
| Where it runs | Hosted by Zoho | You run it yourself: a Rust service, a Svelte interface and PostgreSQL |
| Focus | Sales automation, CPQ, forecasting and multichannel engagement | Sales, marketing, support and analytics, with consent first |

## Where Zoho CRM is stronger

- It is a supported commercial product with a free way to begin, and this project is demo software.
- It has CPQ, sales force automation and real-time engagement across channels.
- A separate product, Bigin, is aimed at small businesses.

## Where this project is different

- You can run the whole system yourself, and read how it works.
- Consent is built into the design: nothing is sent without it.
- It keeps a reference to a person rather than a copy of their details.

## Which suits you

- Choose Zoho CRM if you want a hosted CRM for a small business, ready to use.
- Try this project if you want to see inside the software or adapt it.
