# Contact Relationship Management and Salesforce

Salesforce is a commercial, cloud-based CRM platform. Contact Relationship Management is open-source demo software, not a production CRM, so this is a fair look at two different things rather than a contest.

## At a glance

| | Salesforce | Contact Relationship Management |
| --- | --- | --- |
| What it is | An AI-powered CRM platform with a unified customer profile | Open-source demo software, driven by its specification |
| Licence | Commercial; you pay for the seats and features you use | MIT, Apache-2.0, BSD-3-Clause, GPL-2.0-only or GPL-3.0-only, at your option |
| Where it runs | Salesforce's cloud; no hardware to maintain | You run it yourself: a Rust service, a Svelte interface and PostgreSQL |
| Focus | Sales, service, marketing, commerce and AI agents (Agentforce), with Slack connected to CRM data | Sales, marketing, support and analytics, with consent first |

## Where Salesforce is stronger

- It is a mature commercial platform, and this project is not: Salesforce is the practice this project models.
- It reaches well beyond this project, into commerce, AI agents and collaboration through Slack.
- There is nothing for you to host or maintain.

## Where this project is different

- You read and run every line: the code, the specification and the tests are public, under your choice of open-source licences.
- It keeps a reference to a person rather than a copy of their name or address, so there is less personal data in the CRM.
- Lead scores come from rules you can read.

## Which suits you

- Choose Salesforce if you need a supported production CRM for a business today.
- Try this project if you want to learn how a CRM works inside, or to study a small consent-first design.
